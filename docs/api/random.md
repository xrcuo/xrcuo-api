# 随机数生成 API

## 功能描述

根据指定的范围，生成一个随机整数。

## 请求格式

```
GET /api/random?min={最小值}&max={最大值}
```

## 请求参数

| 参数名 | 类型 | 必填 | 默认值 | 描述 |
|-------|------|------|-------|------|
| `min` | int | 否 | 0 | 随机数最小值 |
| `max` | int | 否 | 100 | 随机数最大值 |

## 响应格式

```json
{
  "code": 200,
  "msg": "请求成功",
  "data": {
    "random": 42
  },
  "took": "0.123ms"
}
```

## 响应字段说明

| 字段名 | 类型 | 描述 |
|-------|------|------|
| `code` | int | 状态码（200成功，400参数错误，500服务器错误） |
| `msg` | string | 提示信息 |
| `data` | object | 随机数数据 |
| `data.random` | int | 生成的随机整数 |
| `took` | string | 请求耗时 |

## 示例请求

```bash
curl YOUR_DOMAIN/api/random?min=1&max=100
```

## 示例响应

```json
{
  "code": 200,
  "msg": "请求成功",
  "data": {
    "random": 42
  },
  "took": "0.123ms"
}
```

## 注意事项

- 生成的随机数范围为 `[min, max]`，包含两端点
- 如果不指定参数，默认范围为 `[0, 100]`
