# 获取公网IP API

## 功能描述

获取当前客户端的公网IP地址。此接口直接返回客户端IP，不涉及JSON包装。

## 请求格式

```
GET /api/ipify
```

## 请求参数

无

## 响应格式

直接返回纯文本IP地址（不包含JSON包装）。

```
123.123.123.123
```

## 示例请求

```bash
curl -H "X-API-Key: your-api-key" http://localhost:8080/api/ipify
```

## 示例响应

```
123.123.123.123
```

## 注意事项

- 此接口直接返回客户端IP地址作为纯文本，不包含任何JSON格式
- 支持通过 `X-Real-IP` 或 `X-Forwarded-For` 头获取真实客户端IP（用于代理场景）
- 如果通过代理访问，返回的是代理之前的真实客户端IP
